# ⚽ Harry Kane - Dashboard de Performance

Este projeto apresenta um dashboard interativo desenvolvido para analisar as estatísticas detalhadas do atacante Harry Kane em diferentes partidas. A aplicação permite visualizar métricas de eficiência, passes e gols de forma dinâmica.

---

## 🎯 Objetivo
Facilitar a análise de dados esportivos através de visualizações gráficas, permitindo identificar padrões de desempenho e eficiência do jogador contra adversários específicos.

## 🛠️ Tecnologias e Bibliotecas
* **Streamlit:** Interface de usuário e interatividade.
* **Pandas:** Estruturação e manipulação dos dados das partidas.
* **Altair:** Criação de gráficos de dispersão e análise estatística visual.

## 📊 Visualizações Inclusas
* **KPIs Globais:** Total de gols, assistências e tempo em campo.
* **Eficiência de Finalização:** Comparativo entre chutes totais e chutes a gol.
* **Consistência de Passes:** Monitoramento do volume e precisão de passes.
* **Correlação Minutos x Gols:** Gráfico de dispersão para análise de produtividade.
