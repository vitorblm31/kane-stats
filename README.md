Painel de Estatísticas: Harry Kane ⚽
Este repositório contém uma aplicação interativa desenvolvida em Python utilizando a biblioteca Streamlit. O objetivo é visualizar e analisar o desempenho detalhado do atacante Harry Kane contra diversos adversários, permitindo uma visão clara de sua eficiência em campo.

📊 Sobre o Projeto
O dashboard processa dados de partidas individuais (gols, assistências, chutes, passes e minutos jogados) para gerar métricas agregadas e visualizações gráficas que facilitam a interpretação da performance do jogador.

Principais Funcionalidades:
Visão Geral (KPIs): Exibição dos totais de gols, assistências, minutos jogados e eficiência de passes.

Filtro Dinâmico: Seleção por adversário para visualizar estatísticas específicas de uma partida.

Análise Gráfica:

Gráfico de barras comparando Gols vs. Chutes.

Gráfico de linha para consistência de passes.

Gráfico de dispersão (Scatter Plot) relacionando minutos jogados e gols marcados.

🛠️ Tecnologias Utilizadas
Python 3.x

Streamlit: Framework principal para a interface web.

Pandas: Manipulação e tratamento dos dados estatísticos.

Altair: Biblioteca de visualização declarativa para gráficos avançados.

O projeto utiliza um conjunto de dados estruturado em formato de lista de dicionários, convertido internamente para um DataFrame do Pandas. As métricas incluem:

Aproveitamento de Chutes: Relação entre chutes totais e chutes ao gol.

Precisão de Passe: Cálculo percentual de passes completos por partida.
